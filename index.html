Methodology

How Distribution Is Calculated

Layer 1: Model Allocation

Each model's ideal unit count is calculated from its YTD sales share percentage, applied to the 550-unit target.

Ideal Units = Sales Share % × 550

Layer 2: Size Distribution

Each model's units are distributed across sizes using a demand curve that peaks at core sizes.

Size Units = Model Units × Size Ideal %

Size Distribution Curve

Core sizes (Women's 7.5-9.5, Men's 9.5-11.5) represent approximately 72% of demand. The ideal curve follows a bell distribution centered on these sizes.
