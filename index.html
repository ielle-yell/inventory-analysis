Methodology

The Process

A systematic approach to inventory health scoring with weighted prioritization for core sizes where 72% of demand exists.

Core Size Weighting

The scoring system applies triple weight to core sizes (Women's 7.5-9.5, Men's 9.5-11.5) because these sizes represent 72% of total demand. Simply adding inventory to edge sizes won't significantly improve your score - you must address the core size gaps to see meaningful improvement.
