Methodology

Scoring Algorithm

The scoring system uses weighted penalties with strict enforcement for wasteful ordering patterns.

How Scores Are Calculated

Core Sizes (5x Weight)

  • -5 pts per percentage point understocked
  • -1 pt per percentage point overstocked

Non-Core Sizes (1x Weight)

  • -0.5 pts per percentage point understocked
  • -4 pts per percentage point overstocked

Order Efficiency Penalty

Orders to non-core sizes while core is underserved receive a 50% score penalty. This prevents "gaming" the system by ordering only edge sizes.
